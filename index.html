    Step 3 · no GPS in the file

    Investigate a photo the geo-sleuth way

    Scripts rank first, you judge only the top few, and every conclusion points at a file. That is geo-sleuth's rule; this tab applies the parts that run in a browser: text extraction, lookup tables, sun and shadow geometry, candidate ranking and an exportable case file.

    Read the picture before you read the metadata: road spec, plates, poles, vegetation, architecture, shadows. The clue checklist is in Reference.

    1. Text in the image (OCR)

    Runs Tesseract.js in a worker on your machine. First use downloads about 12 MB from a CDN; nothing is uploaded.

    No OCR run yet.

    2. Sun and shadow geometry

    The NOAA solar position algorithm runs locally (same maths as geo-sleuth's sun.py: azimuth and elevation to about 0.01°, with refraction).

    Sun at a place and time

    Pakistan = +5, Beijing = +8, Berlin = +2 in summer.

    Shadow length to sun elevation

    1.0 means the shadow is as long as the object is tall.

    Shadow bearing is the sun bearing + 180°.

    Time plus shadow → latitude band

    Given a known capture time (UTC) and a measured sun elevation or shadow ratio, the matching latitudes form a band. Add a shadow bearing and it narrows to a band that is also day-time correct.

    3. Reverse image search hand-off

    No key-free API does reverse image search from a page (they block automated uploads), so this does the honest thing: it prepares the file and opens the engine with the right steps. It never pretends to have results.

      4. Candidate board

      Ranking is likelihood based, like geo-sleuth's board.py: each candidate starts at 1, "for" evidence multiplies, "against" divides, and the tier you report is the finest level rated medium or better.

      5. Confidence tiers

      Report the finest level that reaches medium or above; a weak building guess does not drag down a solid area call.

      Step 4 · measurement

      Coordinate and camera geometry lab

      Turn distances from the picture into metres, convert between the datums that matter, and read the terrain around a point. Every tool here is unit-checked in the test suite.

      Coordinate converter

      In China the same point differs by several hundred metres between WGS84 and GCJ-02. Reading a Chinese map label and using it as GPS coordinates is one of the most common geolocation mistakes.

      Distance, bearing and destination

      click the map to read a position

      Camera to distance

      Equivalent focal length to field of view, then a known real size in the frame to a distance. This is the "pier ruler" trick from geo-sleuth case 1.

      Evenly spaced structures → camera distance

      Sun path for a day

      Terrain horizon at a point

      Samples the free elevation API on rings around the point and draws the true horizon. Use it to compare with a ridgeline in a photo.

      Horizon chart

      Compute a horizon to fill this chart. Zero degrees is level with the camera eye; negative numbers are ground below the horizon line.
